# Document Portal

A full-stack document portal application with login, preview, and pay-to-access features.

## Features

- User authentication (login/logout)
- Document grid view with previews
- Pay-to-access functionality
- Admin panel for document management
- Skeuomorphic UI design inspired by Apple

## Tech Stack

- Frontend: React, Material-UI
- Backend: Node.js, Express
- Database: SQLite
- Authentication: JWT

## Installation

### Backend Setup

```bash
cd server
npm install
npm start
```

The backend will run on http://localhost:3001

### Frontend Setup

```bash
cd client
npm install
npm start
```

The frontend will run on http://localhost:3000

1. Login with either user or admin credentials
2. Browse available documents
3. Click on a document to view preview
4. Enter access code (1234) to view full content
5. Admin users can upload new documents through the admin panel
